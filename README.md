# 🎮 Bored? Meet the Ultimate Word Guessing Game!

Ready to test your full-stack knowledge? This game will help you brush up on key web development terms in a fun, interactive way. Read the description, guess the hidden word, and see if you can beat the game!

## 💡 Stuck?
Hints will help you reveal the hidden word when things get tough!

## ⚠️ WARNING (Rules of the Game)
* You only get a descriptive sentence and **3 hints** to figure it out.
* Choose carefully! You are only allowed **5 wrong guesses** before it's GAME OVER.

# 🛠️ Installation & Setup

Want to run this project locally? Just follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone 

2. Open your terminal and navigate to the project folder.

3. Install the dependencies:
    ```bash

    npm install

4. Start the development server:
    ```bash

    npm run dev

5. Play the game! Open your browser and go to http://localhost:5173/.
